# `train/data/` — Training Datasets (not included)

This directory is **intentionally empty** in the anonymous release. Training data `.jsonl` files are not bundled for two reasons:

1. **Anonymity**: our HuggingFace dataset repositories of the final curated corpora would de-anonymize the authors.
2. **Size**: the full hybrid-thinking corpora (naive-mix 140k and superior-reasoning 27k+27k / 65k+27k) total several GB of JSONL.

All source datasets we draw from are **publicly available**, and the full construction pipeline is included under `src/datasets/`. Reviewers who wish to regenerate the datasets can follow the procedure below.

## Expected files (after reconstruction)

Filenames are referenced by the `dataset` field of each YAML in `train/tasks/`.

```
train/data/
├── naive_mix_20k.jsonl
├── naive_mix_140k.jsonl
├── superior_reasoning_27k_27k.jsonl
├── superior_reasoning_65k_27k.jsonl
├── superior_hybrid_37k_37k.jsonl
├── superior_hybrid_65k_65k.jsonl
└── ...
```

## Construction pipeline

The dataset construction code lives under `src/datasets/`. The high-level flow:

### 1. `/think` branch — high-quality CoT samples

Prepare Chain-of-Thought training samples from public CoT datasets:

```bash
python -m src.datasets.prepare_think_data \
  --source <public-dataset>  \
  --output train/data/think_raw.jsonl
```

Sources used in the paper:
- **OpenR1-Math** — `open-r1/OpenR1-Math-220k` (public, CC-BY)
- **Numina-Math-CoT** — `AI-MO/NuminaMath-CoT` (public)
- **DeepSeek-R1 distillation traces** — reasoning traces generated by `deepseek-ai/DeepSeek-R1`

### 2. `/no_think` branch — direct-answer samples

The `/no_think` samples are constructed by rewriting CoT answers into concise direct answers using an external reasoning LLM:

```bash
# Option A: use DeepSeek-R1 for rewriting
python -m src.datasets.rewrite_no_think_deepseek \
  --input train/data/think_raw.jsonl \
  --output train/data/no_think_raw.jsonl

# Option B: use Gemini
python -m src.datasets.rewrite_no_think_gemini \
  --input train/data/think_raw.jsonl \
  --output train/data/no_think_raw.jsonl

# Option C: generate from scratch
python -m src.datasets.generate_no_think_data --output train/data/no_think_raw.jsonl
```

> **Note**: rewriting requires API access to DeepSeek-R1 or Gemini. Put your key in the standard env var (`DEEPSEEK_API_KEY` / `GOOGLE_API_KEY`) before running. No keys are shipped in the repository.

### 3. Quality filters

Filter low-quality `/no_think` rewrites (those that leak CoT):

```bash
python -m src.datasets.filter_no_think_data \
  --input train/data/no_think_raw.jsonl \
  --output train/data/no_think_filtered.jsonl
```

### 4. Length filtering (27k/65k selection)

The "superior-reasoning" variants in the paper are constructed by selecting the top N samples by token length under the PLE tokenizer:

```bash
python -m src.datasets.filter_by_token_length \
  --input train/data/think_raw.jsonl \
  --output train/data/think_27k.jsonl \
  --max_samples 27000
```

See `src/datasets/filter_by_token_length.py` for the exact cutoff logic.

### 5. Merge into the final hybrid corpus

Combine `/think` and `/no_think` samples into the final JSONL that the YAML configs consume:

```bash
python -m src.datasets.merge_hybrid_dataset \
  --think train/data/think_27k.jsonl \
  --no_think train/data/no_think_27k.jsonl \
  --output train/data/superior_reasoning_27k_27k.jsonl
```

Each training YAML under `train/tasks/` has a `dataset:` field pointing to the name of one of the final JSONL files.

### 6. Token statistics (optional)

After construction, sanity-check the token-length distribution:

```bash
python -m src.datasets._token_stats
```

## Token budget

- **naive-mix 140k**: ~140,000 samples, mean length ~1,000 tokens (Qwen2 tokenizer).
- **superior-reasoning 27k+27k**: 27k `/think` (high-quality, ~3,000 avg tokens) + 27k `/no_think` (curated, ~300 avg tokens).
- **superior-reasoning 65k+27k**: scaled `/think` to 65k.
- **superior-hybrid 37k+37k / 65k+65k**: ablation variants with balanced think/no_think ratio.

## Notes

- All HuggingFace dataset IDs mentioned above are **public** and do not reveal author identity.
- External API usage (DeepSeek / Gemini) introduces cost; for review-time reproducibility, consider using a single small subset (e.g., 1k samples per side) to validate the pipeline end-to-end.
